# Peritajes Mecánicos Forenses — Claudio Durán Alvial

Sitio web estático de peritajes mecánicos con especialidad forense (Chile, jurisdicción nacional).

## Estructura

| Archivo / carpeta | Contenido |
|---|---|
| `index.html` | Página principal: hero, servicios, especialidad forense, proceso, galería, testimonios, blog, FAQ y contacto |
| `blog/` | Tres artículos SEO: peritaje forense, siniestro rechazado y vicios ocultos |
| `assets/` | Casillas para las fotografías reales de la galería (ver su README) |

Todo es HTML/CSS/JS puro, sin dependencias ni build: se abre directo en el navegador y se puede servir desde cualquier hosting estático (GitHub Pages).
